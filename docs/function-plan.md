# แผนฟังก์ชัน: Little Nightmares แบบมุมบุคคลที่หนึ่ง

> เขียน 7 ต.ค. 2026 · **แผนนี้ยังไม่ได้สร้าง** รอเจ้าของขอทีละชิ้น
> หลักการ: ทุกฟังก์ชันอ้างว่า Little Nightmares (LN) ทำยังไง พร้อมแหล่ง · ส่วนที่ Claude คิดเองเขียนกำกับว่า **(Claude)**
> เนื้อเรื่อง เรฟภาพ และเรฟบท เจ้าของส่งมาทีหลัง แผนนี้เป็นแค่ "เครื่องยนต์" ที่ใส่เนื้อหาได้

## 3. ลำดับสร้างที่เสนอ (ทำทีละชิ้น เจ้าของเล่นก่อนชิ้นถัดไป)
| ชิ้น | ทำอะไร | เจ้าของเล่นแล้วตัดสินอะไร | ต้องใช้ของจากเจ้าของ |
|---|---|---|---|
| 1 ✅ | ตัวผู้เล่น + ห้องกล่องเทา | ความรู้สึกของท่าต่าง ๆ | ไม่มี |
| 2 | เสียงที่ผู้เล่นทำ + พื้นผิว + ที่ซ่อน | เบาหรือดังพอดีไหม ซ่อนแล้วรู้สึกปลอดภัยหรือลุ้นไหม | ไม่มี (ใช้เสียงชั่วคราว) |
| 3 | มอนกล่องเทาหนึ่งตัว ได้ยินอย่างเดียวแบบ Janitor + สถานะเดินตรวจ สงสัย ไล่ จับ + ล่อด้วยของขว้าง | มอนฉลาดหรือโง่ไป · หนีทันไหม | ไม่มี |
| 4 | ถูกจับ → ตาย → เช็กพอยต์ + โลกรีเซ็ต | กลับมาเล่นต่อเร็วพอไหม | ไม่มี |
| 5 | เสียงหัวใจ + ชั้นเสียงบรรยากาศ + เสียงมีตำแหน่ง | น่ากลัวขึ้นไหม | เสียงจริงถ้ามี |
| 6 | ฉากไล่ล่าหนึ่งฉาก + คัตซีนสั้นหนึ่งฉาก | ตื่นเต้นไหม | ท่าของมอนถ้ามี |
| 7 | ปริศนาพื้นฐาน (สวิตช์ ประตู กุญแจ) | ใช้ง่ายไหม | ไม่มี |
| 8 | **ด่านทดสอบหนึ่งบท** ตามจังหวะ 4 ขั้นของ LN → export เป็น .exe | scope กับ gameplay รอดไหม | เรฟหรือบทของบทนั้น |

ก่อนเริ่มแต่ละชิ้น Claude ส่งสเปกสั้นให้เจ้าของตอบ "ทำ" ก่อน และอ่านเอกสาร Godot ที่เกี่ยวข้องก่อนเขียนโค้ด เช่น NavigationAgent3D, AnimationTree, AudioStreamPlayer3D

## 4. เรื่องที่ LN ตอบให้ไม่ได้ เพราะ LN ไม่ใช่มุมบุคคลที่หนึ่ง (เจ้าของตัดสิน)
- ผู้เล่นเห็นมือหรือขาตัวเองไหม (โปรเจกต์เก่า เจ้าของเคยตัดสินว่า "เห็น" ยังใช้อยู่ไหม)
- ตอนถูกจับ กล้องแสดงยังไง เพราะ LN มองจากด้านข้าง
- มีอาวุธหรือการสู้ไหม (LN ภาค 1 ไม่มี)
- ขนาดตัวผู้เล่นเทียบกับมอน (LN เป็นเด็กตัวเล็กในโลกยักษ์)

## 5. สิ่งที่ Claude ตัดสินไม่ได้
ความน่ากลัว ความลื่นของการเล่น และจังหวะการไล่ล่า เจ้าของต้องเล่นแล้วบอกเอง เทสที่ Claude เขียนเองใช้กันพังเท่านั้น
