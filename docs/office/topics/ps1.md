# ชิ้น PS1 (PS)

### PS-01 #งาน #จอดไว้ #ชัด
สรุป: ทำเกมสยองขวัญอาร์ตสไตล์ PS1 · เจ้าของให้เริ่มจากชุดความคิดของบอทก่อน (ทำแล้วเป็นชิ้น 0 ดู SK-06) ส่วนภาพสไตล์ PS1 ยังไม่เริ่ม · ผมค้นในรีโปแล้วไม่พบคำว่า ps1 / psx / vertex snap / affine / dither · แอสเซตเดิมเป็น Poly Haven แบบสมจริง และด่าน 1 เป็นทุ่งสว่าง จึงเป็นทิศทางใหม่
ต้นฉบับ: "ทำเกมสยองขวัญ อาร์ทสไตร์ps1 เริ่มจากออกแบบชุดความคิดของบอทให้ตรกับสำตล์การทำงานของฉันก่อน"
ผลต่องาน: ชิ้นถัดไป เมื่อเจ้าของสั่ง ผมส่งสเปกผ่าน `piece-spec` ให้ตอบ "ทำ"

### PS-02 #คำถาม #จอดไว้
สรุป: คำถามที่เป็นของเจ้าของ ตอนเริ่มชิ้น PS1: ใช้กับทั้งเกมหรือบางฉาก · ความละเอียดภาพ · อาการไหนที่เอา (จุดยอดสั่น พื้นผิวเบี้ยว ดิเธอร์ สีน้อย) · แปลงแอสเซตเดิมไหม · เกณฑ์ FPS 60 ยังใช้เหมือนเดิมไหม
ต้นฉบับ: (คำถามของผม ยังไม่มีคำตอบ)
ผลต่องาน: ก่อนค้นเอกสาร Godot เรื่อง spatial shader ผมบอกหัวข้อที่จะค้นและคำถามที่ต้องตอบก่อน
