# ประตูตีความ (ด่านแรก)

**เหตุผล:** ตีความผิดแล้วทำไม่ตรงบรีฟเป็นปัญหาหนักสุดของเจ้าของ ด่านนี้ใช้ไม่กี่บรรทัดและกันงานผิดทั้งชิ้น

**โหมดประตู:** แยกตามประเภทงาน (ค่าเริ่มที่ Claude ตั้ง · เจ้าของเปลี่ยนได้โดยแก้บรรทัดนี้)

## เช็กลิสต์ (คัดลอกไปติ๊กทุกข้อความ)
```
- [ ] 1 อ่าน docs/office/INDEX.md ทั้งไฟล์ แล้วเปิดเฉพาะรายการ ID ที่เกี่ยวข้อง
- [ ] 2 แยกข้อความเป็นรายการย่อย หนึ่งเรื่องต่อหนึ่งรายการ จัดตามเนื้อหา
- [ ] 3 ต่อรายการ เขียน "ผมเข้าใจว่า…" ประโยคเดียว + ป้ายความมั่นใจ ชัด / เดา / ไม่เข้าใจ
- [ ] 4 ตามคำอ้างอิงให้ครบ: เลขข้อ, "อันนี้/อันนั้น", คำพิมพ์ผิด → เทียบข้อความก่อนหน้าและ glossary.md
- [ ] 5 ข้อที่เดาหรือไม่เข้าใจ ถามครั้งละหนึ่งข้อ ในรูป "ผมเข้าใจว่า A หรือ B?"
- [ ] 6 ใช้กติกาประตูตามประเภทงาน
- [ ] 7 จดรายการที่มีผลต่องานถัดไปลง docs/office/ แล้วอัปเดต INDEX.md
- [ ] 8 ส่งต่อ think-first (เลือกแนวทาง) หรือ piece-spec (สร้างชิ้นงาน)
```

## กติกาประตู
- **งานสร้าง** (เขียนหรือแก้ไฟล์งานเกม · ลบ · ทับของเดิม · push · ส่งงานออกไปสปาร์ค): สรุปบรีฟครบ 7 ช่อง จบด้วยบรรทัด `รอคำว่า "ตรง"` แล้วเริ่มเมื่อได้รับคำนั้น
- **งานคุย** (ถาม ค้น อธิบาย ระดมความคิด): ตอบได้เลย ถ้ามีส่วนที่เดาให้ขึ้นต้นด้วยบรรทัด "ผมเข้าใจว่า…"
- **ข้อความที่มีทั้งสองแบบ:** ตอบส่วนคุยทันที ส่วนสร้างเข้ากติกางานสร้าง

## บรีฟ 7 ช่อง
1. เป้าหมาย
2. ผลที่เจ้าของอยากเห็น
3. ขอบเขต: ทำ · ยังไม่ทำ · ของเดิมที่แตะ
4. ค่าจากเจ้าของ (ยกคำต้นฉบับ)
5. ค่าเริ่มที่ Claude ตั้ง
6. เกณฑ์ที่เจ้าของใช้ตัดสิน
7. เรื่องที่จอดไว้

ช่องที่ว่างให้ถามเจ้าของ หรือเติมเป็น "ค่าเริ่มที่ Claude ตั้ง" พร้อมเหตุผลสั้น ๆ

## วิธีจด (docs/office/)
- **จดอะไร:** ความชอบ ข้อกำหนด การตัดสินใจ งาน คำถามที่ค้าง ข้อมูลอ้างอิง ส่วนบทสนทนาทั่วไปอยู่ในแชทอย่างเดียว
- **รูปแบบรายการ:** หัวข้อ `### ID #ประเภท #สถานะ #ความมั่นใจ` ตามด้วย สรุป · ต้นฉบับ · ผลต่องาน
- **ต้นฉบับ:** ยกคำที่เจ้าของพิมพ์ทั้งประโยคในเครื่องหมายคำพูด รวมคำพิมพ์ผิดตามเดิม เพื่อย้อนตรวจว่าตีความตรงหรือไม่
- **ID:** รหัสไฟล์เรื่อง + เลขลำดับ เช่น `SK-03` ไม่ใส่วันที่
- **คำแท็ก** ใช้เฉพาะคำในรายการของ INDEX.md เจ้าของเพิ่มคำใหม่ได้ ผมเพิ่มลง INDEX.md ทันที
- **สถานะ #เสร็จ** ใช้เมื่อเจ้าของยืนยันเอง งานที่ผมทำแล้วใช้ #รอตรวจ
- **อัปเดต INDEX.md ทุกครั้งที่จด** ให้ 1 รายการ = 1 บรรทัด (ID · แท็ก · สรุปไม่เกิน 1 บรรทัด · ไฟล์)
