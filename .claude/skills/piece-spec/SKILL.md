# สเปกสั้นของหนึ่งชิ้น

ส่งสเปกนี้ให้เจ้าของ แล้วรอคำว่า **"ทำ"** ก่อนเริ่มเขียนโค้ด ทำทีละชิ้น

## แม่แบบ (เติมให้ครบทุกบรรทัด ความยาวไม่เกินครึ่งหน้า)
```
ชิ้น: <ชื่อ>
ทำอะไร: <1–2 ประโยค>
อ้าง LN ตรงไหน: <LN ทำยังไง + ลิงก์ · ถ้ามีแหล่งเดียวเขียน "ต้องยืนยันเพิ่ม">
ค่าจากเจ้าของ: <รายการ>
ค่าเริ่มที่ Claude ตั้ง: <รายการ + เหตุผลสั้น ๆ · เจ้าของปรับได้ใน Inspector (@export)>
เอกสาร Godot ที่จะอ่าน: <หน้า / ชื่อคลาส>
วิธีตรวจ: <เทสกันพังตัวไหน · ภาพที่จะถ่าย · FPS เทียบเกณฑ์ 60>
เจ้าของเล่นแล้วตัดสิน: <ความรู้สึกหรือเกณฑ์ที่เจ้าของจะดู>
งานเดิมที่กระทบ: <ไฟล์ที่เจ้าของแก้ไว้ และวิธีเก็บไว้ครบ>
```
จบสเปกด้วยบรรทัด: `รอคำว่า "ทำ"`

## หลังเจ้าของตอบ "ทำ"
1. อ่านเอกสารทางการของ Godot ตามที่ระบุ แล้วบอกว่าอ่านหน้าไหน
2. สร้างตามสเปก โดยให้ค่าที่ปรับได้เป็น `@export` พร้อมคอมเมนต์ `##` ภาษาไทย สคริปต์สั้น หนึ่งไฟล์ทำหน้าที่เดียว
3. รันเทสกันพังและถ่ายภาพจริง (ทำบนเครื่องที่มี Godot 4.8-dev7)
4. ส่งต่อให้ `report-result` เขียนรายงาน แล้วรอเจ้าของเล่นก่อนเริ่มชิ้นถัดไป
