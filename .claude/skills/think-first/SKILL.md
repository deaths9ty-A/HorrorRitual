# คิดก่อนลงมือ

คิดให้เต็มที่ในส่วนระบบและเทคนิค แล้วส่งการตัดสินดีไซน์ เนื้อเรื่อง และทิศทางภาพให้เจ้าของเลือก

## ลำดับคิด
1. **อ่านคำสั่งคู่บริบท** เปิด `CLAUDE.md`, `docs/function-plan.md` และข้อความก่อนหน้า แล้วสรุปที่เข้าใจเป็นหนึ่งบรรทัด
2. **เทียบความหมาย** ถ้าตีความได้สองทาง ให้เขียนทั้งสองทางในบรรทัดเดียวแล้วถามเจ้าของ รอคำตอบก่อนเริ่ม
3. **แยกที่มาของทุกค่า** เป็น 3 กอง
   - เจ้าของกำหนด: ใส่ตามนั้น
   - มีแหล่งอ้างอิง (LN, เอกสาร Godot): ใส่ลิงก์หรือชื่อหน้า
   - Claude ตั้ง: เขียนกำกับว่า "ค่าเริ่มที่ Claude ตั้ง"
4. **เสนอทางเลือก 2–3 ข้อ** พร้อมข้อดี ข้อเสีย และข้อที่แนะนำหนึ่งข้อ ติดป้าย (Claude เสนอ) ให้เจ้าของเลือก
5. **เช็กงานเดิมของเจ้าของ** ถ้างานที่จะทำกระทบฉากหรือไฟล์ที่เจ้าของแก้ไว้ ให้เลือกทางที่สร้างไฟล์ใหม่ข้างไฟล์เดิม หรือถามเจ้าของก่อนเขียนทับ
6. **บอกก่อนค้น** เขียนหนึ่งบรรทัดว่าจะค้นอะไร เพื่อตอบคำถามไหน แล้วค่อยค้น
7. **เลือกสกิลถัดไป** งานสร้างชิ้นใหม่ไปที่ `piece-spec` · งานจบแล้วไปที่ `report-result`

## ภาษา
ตอบเจ้าของเป็นภาษาไทย เขียนตรงว่าจะทำอะไร ใช้ประโยคบอกการกระทำ
